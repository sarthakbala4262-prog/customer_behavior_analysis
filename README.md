# 🛍️ Customer Behavior Analysis

> A data analytics project showcasing customer behavior analysis using **Python, SQL (MySQL) and Power BI**.

---

## 📌 Project Overview

This project analyzes customer shopping behavior using transactional data from **3,900 purchases** across various product categories. The goal is to uncover insights into **spending patterns, customer segments, product preferences, and subscription behavior** to guide strategic business decisions.

---

- **Customer demographics:** Age, Gender, Location, Subscription Status
- **Purchase details:** Item Purchased, Category, Purchase Amount, Season, Size, Color

## 🔄 Project Steps

### 1. Exploratory Data Analysis (Python)
- **Data loading:** Imported the dataset using Pandas
- **Initial exploration:** Used `df.info()` to check structure and `df.describe()` for summary statistics
- **Missing data handling:** Checked for null values and filled missing `Review Rating` values with the **median rating of each product category**
- **Column standardization:** Renamed columns to snake_case for readability (e.g. `purchase_amount_(usd)` → `purchase_amount`)
- **Feature engineering:**
  - Created an `age_group` column by binning customer ages into four groups (Young Adult, Adult, Middle-aged, Senior)
  - Created a `purchase_frequency_days` column by converting text frequencies (Weekly, Monthly, Quarterly, etc.) into number of days
- **Data consistency check:** Verified that `discount_applied` and `promo_code_used` were redundant, then dropped `promo_code_used`
- **Database integration:** Connected Python to MySQL and loaded the cleaned DataFrame for SQL analysis

📓 Notebook: [`Customer_shopping_behaviour_analysis.ipynb`](Customer_shopping_behaviour_analysis.ipynb)

### 2. Data Analysis (SQL)
Structured analysis in **MySQL** to answer 10 key business questions:

1. **Revenue by Gender:** Compared total revenue generated by male vs. female customers
2. **High-Spending Discount Users:** Identified customers who used discounts but still spent above the average purchase amount
3. **Top 5 Products by Rating:** Found products with the highest average review ratings
4. **Shipping Type Comparison:** Compared average purchase amounts between Standard and Express shipping
5. **Subscribers vs. Non-Subscribers:** Compared average spend and total revenue across subscription status
6. **Discount-Dependent Products:** Identified 5 products with the highest percentage of discounted purchases
7. **Customer Segmentation:** Classified customers into New, Returning, and Loyal segments based on purchase history
8. **Top 3 Products per Category:** Listed the most purchased products within each category
9. **Repeat Buyers & Subscriptions:** Checked whether customers with more than 5 purchases are more likely to subscribe
10. **Revenue by Age Group:** Calculated the total revenue contribution of each age group

🗄️ All queries: [`customer_shopping_behavior.sql`](customer_shopping_behavior.sql)

### 3. Dashboard (Power BI)
Built an interactive dashboard to present the insights visually.

📊 Dashboard file: [`Customer_Behavior_Dashboard.pbix`](Customer_Behavior_Dashboard.pbix)

## ▶️ How to Run

### Prerequisites
- Python 3.9+
- MySQL Server
- Power BI Desktop

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/sarthakbala4262-prog/customer_behavior_analysis.git
cd customer_behavior_analysis

# 2. Install dependencies
pip install pandas mysql-connector-python sqlalchemy jupyter

# 3. Run the notebook
jupyter notebook Customer_shopping_behaviour_analysis.ipynb
```

> ⚙️ **Note:** Update the CSV file path and your MySQL credentials in the notebook before running it.

**SQL:** Run the queries in `customer_shopping_behavior.sql` against the `Customer_Behaviour` database.

**Power BI:** Open `Customer_Behavior_Dashboard.pbix` in Power BI Desktop, update the data source if prompted, then click **Refresh**.
